# 节点 01 · 引擎/仓库画像识别 (R1.1 / R1.4 / Q2)
- 类型：按需读取（一次定，写 .helix/config）
- 输入：仓库根目录
- 输出：`.helix/config`{ engine, profile(light|heavy), unmergeable_globs }
- 触发：仓库首次接入
- 逻辑（可追加引擎注册表）：
  - 命中引擎标志 → heavy + 加载该引擎规则：
    - Unity: `ProjectSettings/ProjectVersion.txt`, `*.unity`, `*.prefab`
    - UE: `*.uproject`, `*.uasset`, `*.umap`
    - 网游/自研引擎：按需 register（追加 globs + 提示词，不改内核）
  - 否则按工作树体积(>1.5GB 或 LFS 占比高) → heavy；其余 → light
- 工具/MCP：vault-server.detect_profile（计划）
- 引擎规则文件：`.helix/engines/{unity,ue,...}.yml`（可追加层）
