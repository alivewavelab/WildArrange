Design Tokens

完整值、使用规则与反例见 design-tokens.json；CSS 可复用值见 design-tokens.css。

  • 颜色：深色基底 + 五区语义色；不作为装饰调色板。
  • 圆角：普通容器最多 4px；pill 只用于状态与 Tweaks launcher。
  • 布局：Zone rail 220px；模块卡 auto-fit 最小宽度 260px；移动端均改为单列。
  • 详情：抽屉最高 84vh / 920px；契约接线台桌面三栏、移动端单列；事件矩阵只在自身容器横向滚动。
  • 状态：default / hover / active / active+hover 成组维护。
  • 动效：150ms 状态、250ms 面板、400ms 入场。
