Agent 固定 Skill 绑定

目标：每个长期 Agent 除了配置 provider/model，还能绑定项目 Skill；外部 Agent CLI 由 Skill 自己封装，Helix 不写死具体厂商。

输入

agents.Jiuwei.skills
项目 .agents/skills/<name>/SKILL.md

→
处理

校验安全名称
解析 Prompt Pack 或项目 Skill
固定挂载到该 Agent

→
输出

Agent 上下文获得 Skill 全文与来源
缺失 Skill 显式报告

边界

Skill 只是可调用能力合同；是否真正隔离上下文由其封装的外部 CLI 决定。绑定 Skill 不绕过 verifier、scope、review、acceptance proof 或 checkpoint。

验收

项目 Skill 能被指定 Agent 挂载；其他 Agent 不继承；非法名称不能穿越目录；未知 Skill 不静默；现有动态 Skill 上限与按需注入保持不变。
