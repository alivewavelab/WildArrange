1. 验证方法

隔离环境

每个场景新建一套外置三根：产品仓（带本地 bare 仓作 origin，task branch push 真实发生）、独立治理仓、独立 WILDARRANGE_STATE_HOME。全程不触碰本机真实运行态，也不改 WildArrange 仓库。接入走公开命令 setup → plan → plan approve → run / parallel run / parallel admit。

真实执行者

一个 50 行的适配脚本把 WildArrange 交来的握手包、审查包原样交给真实 claude -p，把模型返回的 JSON 原样回传；Worker 模式下由真实模型按任务描述在任务 worktree 内写文件。同时记录每次调用读到的包路径与挑战码，作为并发与旧回执的证据。

故障注入（只在适配层）

  • 旧回执：用上一次真实回执替换本次回执
  • 超时：executionReadiness.timeoutMs=3000，真实模型约需 8 秒
  • 审查期间改源码：审查开始时向 Worker 产出追加一行
  • 回滚失败：审查时把 src/ 设为只读，或改动已合入文件，并让审查者崩溃
WildArrange 本身不打桩。

3. 第 5 项发现的缺陷（PR #18）

P1

回滚未完成时仍启动其它任务的 Worker

根因：runNextTask 只在「没有可运行任务」时检查 admission 认领；还有独立任务可跑时整段被跳过。已有守卫只覆盖 contract 任务。
修复：守卫改名 assertAdmissionWorkspaceAvailable，覆盖任何回滚失败且仍保留认领的任务；parallel run 也接入。run、workflow、parallel run 统一报 recovery_required: task T001 has unrestored admission changes。
P1

patch 回滚失败被当成成功

根因：git apply --reverse 删不掉文件时只打印 warning: unable to unlink，退出码仍为 0（在空仓库中独立复现）。系统据此记 rolled_back、释放认领，子 Agent 文件留在客户项目里，上一个缺陷的保护也就不会触发。
修复：反向补丁后再跑正向 git apply --check：只有工作区每个路径都确实回到 pre-image 才算回滚完成。比反向检查更严，部分回滚也能识别。
回归测试（先红后绿）：test/checkpoint-integrity.test.mjs 中 “an unfinished rollback stops run and parallel run from starting any other worker” 与 “patch rollback that git only warns about is reported as rollback_failed”。
实机复测：两种真实回滚失败（只读目录、补丁冲突）下 admit 均为 recovery_required / rollback_failed；run、workflow、parallel run 全部拒绝；恢复期间模型调用 0 次，T002 保持 pending。

5. 范围与局限

  • 真实执行者只用了 claude -p（Claude Code 2.1.287，sonnet）。Codex、Cursor、Kimi 客户端未手动驱动；第 1 项经真实安装的 Codex Hook 桥接验证，非客户端界面。
  • 回滚失败、审查期间改源码、旧回执由适配层故障注入制造；被测的 WildArrange 流程本身未打桩。
  • 仅在 macOS（Darwin 25.6，Node v26.3.0）验证；Windows 未覆盖。
  • 修复后的恢复路径（同一 run 修好文件系统后重新 admit）由既有自动化测试覆盖，未在实机重跑。

6. 复现方法

每个场景：建产品仓与 bare origin → wildarrange setup --governance-root <gov> → 在治理仓 policy/wildarrange.config.json 把 executionReadiness.workerProbe 与 review.responsibility.command 设为下面的适配脚本并提交 → 导入计划、批准 → 执行对应命令。计划中 worker_command 为 node agent.mjs worker。

适配脚本 agent.mjs（真实 claude -p + 故障注入开关） 
// 真实适配器：把 WildArrange 包交给真实 claude -p，原样返回其 JSON。
// 用法：node agent.mjs probe|worker [--replay-stale|--mutate-during-review|--sabotage-rollback|--conflict-rollback]
import { spawnSync } from "node:child_process";
import { appendFileSync, readFileSync, existsSync, writeFileSync } from "node:fs";
import path from "node:path";
const here = path.dirname(new URL(import.meta.url).pathname);
const log = (entry) => appendFileSync(path.join(here, "agent-log.jsonl"), JSON.stringify({ at: new Date().toISOString(), pid: process.pid, ...entry }) + "\n");
const mode = process.argv[2];
const claude = (prompt, extra) => {
  const r = spawnSync("claude", ["-p", "--model", "sonnet", "--output-format", "json", "--no-session-persistence", ...extra], { input: prompt, encoding: "utf8", maxBuffer: 64 << 20 });
  if (r.status !== 0) { log({ mode, error: r.stderr.slice(0, 500) }); process.exit(1); }
  return JSON.parse(r.stdout);
};
if (mode === "worker") {
  const t = JSON.parse(readFileSync(process.env.WILDARRANGE_EXECUTION_CONTEXT, "utf8")).task;
  log({ mode, task: t.id, cwd: process.cwd() });
  const out = claude(`You are a worker in ${process.cwd()}. Task: ${t.subject}\n${t.description || ""}\nOnly create or edit files under: ${t.writable_paths.join(", ")}. Do it now, then reply DONE.`,
    ["--permission-mode", "acceptEdits", "--allowedTools", "Read", "Write", "Edit"]);
  log({ mode, task: t.id, result: String(out.result).slice(0, 200), cost: out.total_cost_usd });
  process.exit(0);
}
const packetPath = process.env.WILDARRANGE_READINESS_PACKET || process.env.WILDARRANGE_REVIEW_PACKET;
const packet = JSON.parse(readFileSync(packetPath, "utf8"));
const flag = (name) => process.argv.includes(name) && !packet.challenge;   // 只作用于审查包
if (flag("--sabotage-rollback")) { (await import("node:fs")).chmodSync(path.join(process.cwd(), "src"), 0o555); process.exit(3); }
if (flag("--conflict-rollback")) { appendFileSync(path.join(process.cwd(), "src", "greet.js"), "// concurrent edit\n"); process.exit(3); }
if (flag("--mutate-during-review")) { /* 向最近一次 Worker 工作目录的 src/greet.js 追加一行 */ }
const out = claude(`You are the external adapter for WildArrange. Below is a JSON packet. Follow packet.instruction exactly. Output only the JSON object, no prose, no code fences.\n\n${JSON.stringify(packet)}`,
  ["--disallowedTools", "Bash", "Edit", "Write"]);
let text = String(out.result).trim().replace(/^```(?:json)?\s*|\s*```$/g, "");
const stalePath = path.join(here, `last-${packet.role || packet.kind}.json`);
if (process.argv.includes("--replay-stale") && existsSync(stalePath)) text = readFileSync(stalePath, "utf8");
else if (packet.challenge) writeFileSync(stalePath, text);
log({ mode, role: packet.role || null, packetPath: path.basename(packetPath), challengeIn: packet.challenge || null, cost: out.total_cost_usd });
process.stdout.write(text);
