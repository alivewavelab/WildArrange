⚠️ 本方案已部分被后续实施决策替代（2026-07-21）。 依赖规则的最终版以 test/dependency-boundary.test.mjs 与 doc/project-architecture.md「Five-Zone Layering」为准。与本文的差异： ① 实施 Phase 4 时发现 hooks/context（宿主生命周期钩子、Agent 上下文构建）必须读取任务板与 attention report，完全剥离编排状态的改造成本过高，故放宽为 AI → Orchestration（只读） 允许； ② AI 层的 scope 预检需要与编排层同一条能力封缝，故放宽为 AI → Capabilities（仅经 gateway） 允许； ③ Orchestration → AI 收紧为逐条钉死的白名单边（目前仅 linear-runtime → ai/routing）。 本文中「AI 不得依赖 Orchestration」「L3a 与 L3b 同级互不依赖」两条按上述决策失效；准确的说法是「五区受控依赖 + 无模块级循环（测试强制）」而非「严格单向」。其余内容（五区划分、能力网关、共享交付流水线、Phase 划分）仍与实施一致。 交接与验证记录见 doc/2026-07-21-five-zone-refactor-handoff.md。

WildArrange 五区解耦重构方案

五区 + 严格单向依赖 + 共享交付流水线 + 静态能力网关 + 零破坏兼容。
面向 vibe coding 维护者：改工作流只动编排区、改功能只动能力区、每步结果一行人话汇总。

一、层级总览（严格单向：上→下）

L1Interface — CLI / Dashboard / Adapters / 兼容 facade
↓
L2Orchestration — 线性运行 / 并行运行 / 共享交付流水线 / 任务板 / 计划状态
↓             ↓
L3aAI — 路由 / 注入 / Hooks / 技能匹配 / LLM / 档案路由 / 规则
L3bCapabilities — Gateway / 验证 / 范围守卫 / 复核 / 验收证明 / 存档 / Worker
↓             ↓
L4Infrastructure — Foundation / Ledger / Security / GitOps / MemoryDigest

铁律：上层可调下层，下层绝不反调上层。L3a 和 L3b 同级互不依赖。dependency-boundary.test.mjs 自动扫描 import 强制执行。

线性运行（linear-runtime）和并行合入（parallel-runtime）共用同一条管道，改 gate 顺序/加新 gate 只动这一处：

→

→
范围守卫
→
复核
→
验收证明
→
存档
→
一行人话汇总
汇总示例：
任务① 搭页面骨架：验证(0.3s) → 范围守卫(0.1s) → 复核(12s, ¥0.02) → 验收 → 存档
总耗时 14s ｜ 总费用 ¥0.02 ｜ 改了 3 文件，全在允许范围

四、能力网关（静态注册 + 统一信封）

静态注册表

所有能力在 gateway.mjs 用 object literal 注册。加新能力 = 写实现 + 这里加一行。

CAPABILITIES = {
  'worker':           runWorker,
  'verify':           runVerifier,
  'scope':            scopeGuard,
  'review':           runReviewGate,
  'acceptance-proof': writeAcceptanceProof,
  'checkpoint':       writeCheckpoint,
}

统一结果信封（6 字段）

字段用途
capability哪个能力
statuspass / fail / inconclusive
evidence留档证据（原样存入账本）
sideEffectnone / state_written / files_changed
duration_ms耗时（毫秒）→ 定位哪步慢
costLLM 费用（无则 null）

六、重构步骤（6 个 Phase）

修 CLI 重复导入 + 加 smoke test + commit 保护工作区 + 拉分支

AI 层独立

搬目录 + 激活边界测试

6

收尾

文档更新 + 旧路径 shim deprecated + 全量验证

十、决策记录

决策项结论
Gate 序列固定顺序，未来可追加新 gate（插入 pipeline），不支持跳过
信封字段6 字段：status / evidence / sideEffect / duration_ms / cost / error
网关首版静态注册，不引入动态插件
兼容旧路径保留一个版本周期
foundation暂不拆（951 行但稳定且无上游依赖）
L3a vs L3b同级互不依赖，都只被 L2 调度
