P2 · 运行时幂等

重复 initRuntime 时，若配置、工作状态和 Prompt Pack 均未变化，不再重复物化、写初始化 ledger 和 snapshot。首次初始化与 Pack 变化仍照常执行。

P2 · 门异常可诊断

能力返回失败信封且 evidence=null 时，线性运行时先处理 pipeline 状态，不再发生二次 TypeError。

P2 · 等待态停止

awaiting_plan_approval 与 revalidation_required 是等待外部动作，不在一次 workflow 内重复空转。

P2 · 坏治理输入降级

损坏的 Prompt Pack manifest/routes 转成明确 P1 finding，审计仍能生成报告，不被单个坏 JSON 击穿。

仓库卫生 · LF

只机械归一已混合的文本文件，并添加 .gitattributes；不借机改写文件内容。

明确保留 · Gateway 合同

command 与 command-safety 已被项目规范和测试公开使用，不属于可删除死注册。

不做

  • 不因 1000 行阈值拆 bin/wildarrange.mjs。
  • 不批量合并无漂移证据的小工具函数。
  • 不建设通用 gate descriptor 框架。
  • 不增加新测试框架或扩张测试矩阵。

验收

  • 新增回归测试逐项通过。
  • npm test 全量通过。
  • npm run check:arch 通过。
  • git diff --check 通过，混合行尾为 0。
