多 Agent 并行与 ArchivistRouter 最小闭环

目标不是一步做满 OMO 集群，而是先让子 Agent 可并发、结果可落盘、档案路由可调用、主线不被脏写。

并行最小闭环

输入
team task / runnable task / runner command
隔离
.wildarrange/agent-runs/<runId>
并发执行
每个子 Agent 读 task packet，写 agent-result.json
收集
stdout / stderr / result / exitCode 入账
Admission
结构化 files 过 writable_paths + verifier + review 后 checkpoint

ArchivistRouter 最小闭环

触发
session start / user prompt / post compact / git head changed / prompt window
过滤
只保留结论、证据、成果物；剔除代码块和 raw diff
语义判断
CangJie 使用 deepseek-v4-flash
归档
memory events / stage summary / index
路由输出
route report / context injection / keyword suggestions

优先级

P0: 本轮实现
  • src/wildarrange-parallel-agents.mjs：命令型子 Agent 并发执行、结果收集、结构化成果 admission。
  • src/wildarrange-archivist-router.mjs：构建 routing packet、可选调用 LLM、hook 触发、写结构化记忆。
  • CLI 暴露 parallel run 与 archivist run。
P1: 下一步
  • Git worktree 隔离和 patch-based merge admission。
  • Codex / Cursor adapter 层接真实子 Agent 启动器。
  • 关键词建议的人工审核与应用命令。
P2: 后续
  • 常驻 Agent 进程管理。
  • 后台 dashboard 展示每个子 Agent 的运行状态。
  • 多 Agent 冲突合并和失败回滚。
安全边界
  • 子 Agent 默认不写主工作区。
  • ArchivistRouter 默认不自动改 routes.json。
  • 无 LLM key 时不阻断线性 workflow。
