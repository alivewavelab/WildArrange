上下文预算运行时改造

结论：废弃 Markdown / Skill 统一 6000 字符静默截断，改为“Prompt 短、Markdown 中、Skill 宽、按注入点收紧、截断必须可见”。借鉴的是 Agent 长上下文治理机制，不复制外部提示词原文。

P0 取消静默截断

src/wildarrange-injection.mjs 返回 chars、loadedChars、budgetChars、truncated。超过预算时正文内加入中文截断提示。

P0 Skill 宽预算

默认已激活 Skill 可加载 80,000 字符；before_execute / before_review 保持宽预算，pre_tool_use / post_tool_use 收紧。

P1 中文治理提示

wildarrange-injection-runtime 增加中文上下文治理哲学：系统提示词是宪法，Skill 是作业指导书，References 是档案库，Hook 是交通灯。

输入
注入点、Markdown 挂载、Skill 挂载、contextBudgets 配置
→
处理组件
resolveInjectionPoint 按内容类型和注入点计算预算并加载
→
输出
带预算元数据的注入块；超限时显式提示而非静默失效
