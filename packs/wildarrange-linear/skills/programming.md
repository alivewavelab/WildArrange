# programming

## 用途

通用编码 skill。适用于实现、修复、重构、小工具、脚本、库代码。

## 工作循环

1. 读规范。
2. 读相关代码。
3. 明确最小改动。
4. 实现。
5. 运行 diagnostics/tests/build。
6. 通过真实表面验证。
7. 汇报改动和证据。

## 工程原则

- 跟随现有模式。
- 小改优先。
- 不做无关重构。
- 不新增依赖，除非必要且被授权。
- 只在系统边界做输入校验。
- 避免 speculative abstraction。
- 错误处理符合项目风格。

## 测试原则

- 有测试基础设施且风险高时补测试。
- 修 bug 时优先加回归测试。
- 没有测试基础设施时，用最小 driver 或真实命令验证。

## 禁止

- 没读代码就改。
- 为绿灯弱化测试。
- 隐瞒失败。
- 声称验证但没实际运行。
