# lcx-report-bug

## 用途

生成高质量 bug report。适合插件、runtime、CLI、MCP、模型路由、prompt-pack、状态恢复问题。

## 必要信息

- 版本和安装方式。
- 操作系统和 shell。
- 复现步骤。
- 预期行为。
- 实际行为。
- 日志和错误输出。
- 相关配置，去除 secrets。
- 最小复现项目或命令。

## 流程

1. 收集环境事实。
2. 最小化复现。
3. 判断是否配置问题。
4. 去除敏感信息。
5. 写 report。

## 输出格式

```markdown
## 摘要
## 环境
## 复现步骤
## 预期行为
## 实际行为
## 日志
## 临时绕过
## 疑似原因
```

## 禁止

- 把猜测写成事实。
- 泄露 token/key/path 中的敏感部分。
- 没复现就声称 root cause。
