# ultraresearch

## 用途

最大饱和研究。只有用户明确要求 `ultraresearch`、`/ultraresearch`、`$ultraresearch` 时启用。

## 核心原则

- 并行饱和：多个角度同时查。
- 递归扩展：每个发现都可能产生新搜索。
- 实证验证：争议性结论尽量跑代码或实验验证。
- 证据优先：最终结论必须有来源、代码证明或明确不确定性。
- 收敛停止：没有新线索时停止，不无限研究。

## 查询拆解

先拆：

- 核心问题。
- 研究轴。
- 本地代码是否相关。
- 外部文档是否相关。
- 是否需要浏览器渲染。
- 是否需要实证验证。
- 是否需要报告产物。

## 来源

- 本地代码：Explore。
- 外部文档：Librarian。
- GitHub/开源：gh / web。
- 官方文档：优先。
- 浏览器页面：需要渲染时使用浏览器工具。

## 输出

根据用户需要输出 Markdown / HTML / PDF / PPTX 等；默认 Markdown。

每条重要结论要有证据。无法证实时标记未知。
