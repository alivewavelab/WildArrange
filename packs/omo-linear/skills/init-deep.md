# init-deep

## 用途

初始化分层 `AGENTS.md` / 项目规则知识库。适合大型或复杂目录，需要 root + 子目录级规则。

## 模式

- update：保留已有规则，补充缺口。
- create-new：读取旧规则后重建。
- max-depth：限制目录深度。

## 流程

1. 并行 discovery：
   - 目录结构。
   - 语言/框架/包管理。
   - 测试/build 命令。
   - 现有规则文档。
   - 复杂子目录。
2. 评分：
   - 是否有独立技术栈。
   - 是否有不同约定。
   - 是否高风险或高变更。
   - 是否值得单独写规则。
3. 生成：
   - root AGENTS。
   - 高分子目录 AGENTS。
4. Review：
   - 去重。
   - 删除空话。
   - 校验命令和路径。

## 规则内容

每份规则应包含：

- 适用范围。
- 构建/测试/运行命令。
- 目录约定。
- 代码风格。
- 禁止事项。
- 验证要求。

## 禁止

- 复制一堆泛化空话。
- 忽略已有规则。
- 为低复杂度目录生成噪声规则。
