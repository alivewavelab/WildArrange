# remove-ai-slops

## 用途

清除 AI 味代码和文档：空泛注释、过度抽象、模板化 UI、无意义日志、重复保护层、解释性废话。

## 检查项

- 注释是否只复述代码。
- 命名是否泛化或营销化。
- helper 是否只被用一次。
- 是否添加未请求配置。
- 是否有“just in case” fallback。
- UI 是否像模板堆砌。
- 文档是否充满维护者视角废话。

## 处理原则

- 删除无价值注释。
- 合并过早抽象。
- 保留真实领域概念。
- 减少不必要状态和分支。
- UI 改成贴合场景的真实体验。

## 禁止

- 为“精简”破坏可读性。
- 删除必要错误信息。
- 删除用户需要的帮助文本。
- 改变行为而不验证。
